Paradise City Outbreak (draft, unbuilt)
Burnout Paradise Remastered is the host. 7 Days to Die is a required companion: its zombie models and sounds are read from the player's own install at runtime and are never copied or shipped.
First version: free roam, solo. Zombies scattered around the city, plus a blood moon horde every 7 in-game days.
Design lives in `sheets/` (source of truth). Status is in `sheets/listing.json`.
